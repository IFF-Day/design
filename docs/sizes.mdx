## Five sizes

Every component with a size offers the same five: `xs`, `sm`, `base`, `lg` and `xl`, passed as `size="sm"`, never as a number. Each step is a token, so a component draws its sizes from `tokens.css` and a page that needs another size picks another step. Posters and shelves take the same names: a poster scales its fallback title and a shelf its column width.

| Component                                                                                             | xs     | sm     | base   | lg     | xl      |
| ----------------------------------------------------------------------------------------------------- | ------ | ------ | ------ | ------ | ------- |
| **Icon** <br /> Lucide glyphs drawn through Icon                                                      | `12px` | `14px` | `16px` | `20px` | `24px`  |
| **Avatar** <br /> The circle; the letter is 42% of it                                                 | `20px` | `28px` | `36px` | `56px` | `112px` |
| **Stars and StarRating** <br /> One star                                                              | `12px` | `14px` | `20px` | `26px` | `30px`  |
| **Button, Input, Select, InputGroup** <br /> The height; a button and a field of one size stand level | `26px` | `31px` | `38px` | `44px` | `52px`  |
| **IconButton** <br /> The round button                                                                | `24px` | `28px` | `34px` | `40px` | `48px`  |

## Usage

- `base` is the default unless a component says otherwise: Stars default to `sm` and the rating input to `xl`.
- To change a size in one context, set the component’s custom property to another step, for example `.creator-head .avatar { --avatar-size: var(--avatar-lg) }`, rather than forcing a width.
