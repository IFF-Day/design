## Sizes

Icons render through `Icon` from `@iffday/ui`, which takes the glyph and one of five sizes from the `--icon-*` tokens; no icon is given a size in pixels.

- `base` (16px) is the most common: action panel rows, menu items, the actions on a review.
- `sm` (14px) goes in buttons, small controls such as Like and tight inline spots; `xs` (12px) beside captions.
- `lg` (20px) goes in round icon buttons and the site header.
- `xl` (24px) is for Watched, Watchlist and Add to plan on film pages and the community page tiles, whose stroke is thinned to 1.6px.

## Usage

- Import icons by name, `import { Heart } from 'lucide-react'`, so the bundle carries only the icons in use, and draw them as `<Icon icon={Heart} size="sm" />`.
- Icons take the text color (`currentColor`). A heart that means selected is filled with `fill="currentColor"`.
- An icon-only button needs an `aria-label`. An icon beside text is decoration: `Icon` hides it from screen readers unless it has an `aria-label` of its own.
