## Example

The heading of personal tool pages: a 35px title and a description on the left, one action on the right, aligned at the bottom. My plans, My tickets, Film diary, Friends and lists, list pages and the CMS dashboard use it. Browsing pages such as Feed, Screenings, Search and the festival directory use [DisplayTitle](https://design.iff.day/components/display-title).
