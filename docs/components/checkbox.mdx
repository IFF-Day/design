## Example

`CheckLabel` is an 18px checkbox with its text inside a `<label>`, so clicking the text toggles it. Checked, the box fills with the primary button color.

<Example name="components/checkbox/basic" />

## Usage

It is controlled: pass both `checked` and `onChange`. Use it for settings that apply as soon as they are ticked. When each state has its own name (Watchlist, On watchlist), use `ToggleButton`.
