## Example

`Avatar` shows the person's picture from `src`, cropped to the circle. Without one it draws the first letter of the name on one of six brand colors, chosen by hashing `seed` (usually the user ID), so a person has the same color on every page. The light grey ground takes dark text and the others light text. `size` is `xs` (20px), `sm` (28px), `base` (36px), `lg` (56px) or `xl` (112px), from the `--avatar-*` tokens; the letter is 42% of the diameter.

## Picture

With `src` the picture fills the circle, cropped to cover it, and its `alt` is the name. A picture that fails to load gives way to the initial, so a missing file never leaves a broken image. On iff.day people's pictures come from `avatarUrl` in the API, on user.filmcdn.com.

## Usage

- Pass `seed` rather than relying on the name: otherwise a new display name changes the color.
- The avatar is decoration and carries `aria-hidden`; write the name beside it, as reviews do.
