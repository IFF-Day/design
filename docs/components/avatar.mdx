## Example

There are no profile pictures yet, so `Avatar` draws a circle with the first letter of the name. The ground is one of six brand colors, chosen by hashing `seed` (usually the user ID), so a person has the same color on every page. The light grey ground takes dark text and the others light text. `size` is `xs` (20px), `sm` (28px), `base` (36px), `lg` (56px) or `xl` (112px), from the `--avatar-*` tokens; the letter is 42% of the diameter.

## Usage

- Pass `seed` rather than relying on the name: otherwise a new display name changes the color.
- The avatar is decoration and carries `aria-hidden`; write the name beside it, as reviews do.
