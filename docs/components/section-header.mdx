## Example

A section title is an 18px `h2`. `count` adds a count badge after it, `to` puts a See all link on the right and `action` holds a button. They combine.

<Example name="components/section-header/basic" stage="fill" />

## Usage

With several sections on a page, give each `SectionHeader` an `id` and point the surrounding `<section>` at it with `aria-labelledby`, so screen reader users can jump between sections. The community page does this.
