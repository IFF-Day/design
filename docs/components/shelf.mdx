## Example

`Shelf` lays its children in one row that scrolls sideways and settles at the start of a tile. `size` sets the column width: `xs` 104px, `sm` 128px, `base` 164px, `lg` 200px and `xl` 240px. On phones the row runs past the page gutter to the screen edge, the gap tightens from 18px to 12px, and every width narrows a step.

## Usage

Give the row a [SectionHeader](https://design.iff.day/components/section-header) that names it and links to the full list. `label` names the row, which a screen reader reads as a list.
