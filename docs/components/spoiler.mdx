## Example

With `spoiler` set, the content is replaced by a button, Contains spoilers. Reveal, and appears once clicked; without it the content shows straight away. The text is already in the page and only waits to render. When the text has to be fetched, open it the way [ShortReview](https://design.iff.day/components/short-review) does.
