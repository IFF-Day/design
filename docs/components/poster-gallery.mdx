## Example

The Film posters section of a film page lists every poster of the film; each opens the original image. Under each poster, [Pill](https://design.iff.day/components/pill) labels mark the language, the festival poster, the main poster and the main poster for a language. When posters carry languages, a language filter appears beside the heading.
