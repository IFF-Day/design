## Example

`Popover` uses the same surface as `Menu`: white, a 10px radius and the popup shadow. Unlike a menu it is not a list of actions, so it can hold anything. Festival directory cards use it for the tags that do not fit: +4 shows them all.

## Usage

For a list of actions use `Menu`; when the reader has to finish something before going on, use `Dialog`. `label` names the popup for screen readers.
