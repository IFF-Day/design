## Radii

The larger the radius, the more an element reads as an object lifted off the page. A poster has 4px and reads as a print; a dialog has 14px and clearly floats. Round avatars and icon buttons use 50%; pill buttons and chips use `--radius-pill`.

- `--radius-xs` **4px** Posters, checkboxes, list covers
- `--radius-sm` **5px** Pills
- `--radius` **8px** Buttons, inputs, selects
- `--radius-lg` **10px** Grey panels, menus, popups, error panels, toasts
- `--radius-xl` **14px** Dialogs and the phone sheet
- `--radius-pill` **999px** Pill buttons and chips, the phone tab bar
