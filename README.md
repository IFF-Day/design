# IFFDAY design

The pages of [design.iff.day](https://design.iff.day), the design system behind [iff.day](https://iff.day): the foundations (brand, colors, typography, sizes, motion, icons, writing) and every control and page block, with their props and uses.

`docs/` holds every page as MDX at the same path as on the site, so `docs/components/button.mdx` is [design.iff.day/components/button](https://design.iff.day/components/button). Live examples appear as `<Example name="…" />` tags and render on the site. The pages are generated from the site's sources, so changes made here are overwritten by the next update.
